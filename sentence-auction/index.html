✏️ Auction sentences

One sentence per line. Start with + if it is correct or - if it is incorrect. For incorrect sentences, you can add the correction after =.
Example: + She plays tennis on Saturdays.   - He play football. = He plays football.
To group sentences into a topic, write a line with ## Topic name before them (for example ## Unit 3).
Lines starting with # are ignored. Changes are saved in this browser.
